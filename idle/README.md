# 全界巡遊録

`/idle/` に追加した、GitHub Pagesでそのまま動く無料の放置RPGです。ビルド、APIキー、ログイン、サーバー、課金、広告、倍速はありません。既存ゲームのセーブには触れません。

## 遊び方

- 5人までの仲間による自動戦闘と自動ステージ進行。5ステージごとにボス、20ステージごとに世界線が変わります。
- レベル育成、重複記憶による5段階の覚醒、戦闘による絆、同じ世界線3人の編成効果。
- イラスト付き80キャラの召喚。確率65%/27%/8%、最高区分は30回天井。石は初期配布・戦闘・試練・ミッションから獲得。
- 3部位・3品質の装備、鍛造、武器/防具の10段階強化、最適装備、分解。護符は会心率を付与。
- 鍛冶場・灯台・書庫の拠点強化、15分/1時間/4時間の遠征。
- 残響の塔、境界の主、実績、日本時間0時更新の日課。
- ステージ40突破で転生。仲間・装備などを残して永久能力ボーナスを獲得。
- オフライン資源は最大12時間。非表示タブでは戦闘を止め、同じ資源蓄積に切り替えます。ステージのオフライン突破はしません。
- 5秒ごとのブラウザ内保存、JSON書き出し/確認付き復元。Web Locks対応ブラウザでは同時タブの上書きを防止。
- 月・星空・オーロラ・多層地形・遺跡・粒子をCanvasで描画。専用技カットイン、ダメージ、効果音切替、動きを控える設定、スマホ対応。

## 原作との関係

`game/index.html` のCSVと世界線一覧、および `illust/` の既存イラストを利用しています。元ファイルのデータや既存の戦闘コードは変更しません。イラストと有効な能力値が揃った80キャラを収録。能力値・技名・プロフィールを引き継ぎ、特性効果はこのゲーム専用の3役割に置き換えています。原作の特性そのものは発動せず、その違いはゲーム内でも明記しています。

## 開発と検証

リポジトリ直下で `python3 -m http.server 8766` を起動し、 `http://localhost:8766/idle/` を開きます。ES ModulesのためHTMLファイルの直接オープンではなくHTTPで配信してください。

`node --test idle/engine.test.mjs`

テスト対象：全画像の存在、報酬上限と二重受け取り防止、育成費用、覚醒、召喚天井と重複、通常/塔/ボス報酬、日本時間の日付更新、転生時の引継ぎ、セーブ検証。

保存キーは `oc-idle-v1`。バックアップには個人情報や認証情報は含まれません。クラウド同期・対人機能はありません。Google Fontsを読めない場合は端末の日本語フォントを使用します。
